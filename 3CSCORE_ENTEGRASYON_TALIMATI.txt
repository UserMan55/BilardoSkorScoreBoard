================================================================================
ADIM 2: YÖNLENDİRME BUTONU (Senin Tarafın)
================================================================================

3cscore.com'da kullanıcıları skorboard'a yönlendirecek buton ekle.
Token zorunlu - olmadan çalışmaz!

REACT ÖRNEK KOD (Firebase v9+):
-------------------------------

import { getAuth } from 'firebase/auth';

function LiveScoreboardButton({ user }) {
  const handleClick = async () => {
    try {
      const auth = getAuth();
      const currentUser = auth.currentUser;
      
      if (!currentUser) {
        alert('Lütfen önce giriş yapın');
        return;
      }
      
      // ⚠️ ZORUNLU: Firebase ID Token al
      const idToken = await currentUser.getIdToken(true);
      
      // URL parametrelerini hazırla
      const params = new URLSearchParams({
        token: idToken,           // ⚠️ ZORUNLU
        userId: currentUser.uid,
        name: user?.fullName || currentUser.displayName || '',
        city: user?.city || '',
        salon: user?.salon || ''
      });
      
      // Yönlendir
      window.location.href = `https://live.3cscore.com?${params.toString()}`;
      
    } catch (error) {
      console.error('Token alınamadı:', error);
      alert('Bir hata oluştu');
    }
  };

  return (
    <button onClick={handleClick}>
      🎱 Canlı Skorboard
    </button>
  );
}

================================================================================
URL PARAMETRELERİ
================================================================================

ZORUNLU:
    token   : Firebase ID Token (getIdToken() ile alınır)

OPSİYONEL:
    userId  : Kullanıcı ID
    name    : Kullanıcı adı (URL encoded)
    city    : Şehir
    salon   : Salon adı

ÖRNEK URL:
https://live.3cscore.com?token=eyJhbGciOi...&name=Ahmet%20YILMAZ&city=Samsun

⚠️  TOKEN OLMADAN ÇALIŞMAZ:
https://live.3cscore.com?name=Ahmet  ← ERİŞİM ENGELLENİR

================================================================================
TOKEN BİLGİLERİ
================================================================================

• Firebase ID Token'lar 1 saat geçerlidir
• Her tıklamada getIdToken(true) ile TAZE token al
• Token'ı localStorage'da SAKLAMA
• Token URL'de HTTPS ile şifrelenir
